the thirty asset marks for the proof band on the home page.

drop one file per asset here, named after the ticker in lower case, svg only:

  btc.svg   eth.svg   usdt.svg  usdc.svg  bnb.svg
  sol.svg   trx.svg   avax.svg  pol.svg   arb.svg
  op.svg    link.svg  uni.svg   aave.svg  dai.svg
  wbtc.svg  shib.svg  pepe.svg  ldo.svg   mkr.svg
  crv.svg   snx.svg   comp.svg  grt.svg   ens.svg
  ape.svg   sand.svg  mana.svg  cake.svg  jup.svg

svg rather than png: an svg takes our colour from one line of css and stays
sharp at any size, where a png in the brand's own colours can only be greyed,
and greyed reads as switched off.

the selection is not a taste question. every asset on that wall settles on a
chain we actually screen: bitcoin, ethereum, solana, bnb chain, polygon,
avalanche, arbitrum, optimism, base and tron. a coin on the wall is a claim that
we cover it, which is why there is no xrp, no cardano and no monero on it. swap
any of the thirty for another that meets that rule, not for one that does not.

until the real files are here the wall draws simplified glyphs inlined in
index.html. they are a placeholder and each cell carries data-coin, so the swap
is one attribute per cell and no change to the layout.
